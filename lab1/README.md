# Лаба 1 — nginx

Основной конфиг — `../docker/nginx.conf`, входная точка — контейнер `frontend`. В нём есть:

1. Перенаправление `http://lab.localhost` → `https://lab.localhost` с кодом 301.
2. Раздача файлов из `frontend/`, проксирование `/api/` на upstream из `backend-a:3000` и `backend-b:3001`.
3. Заголовок `X-Backend-Instance`, по которому видно чередование экземпляров.
4. `alias` для `/docs/` из отдельной папки `docs/`.
5. Отдельный сервер `other.localhost` и ответ 421 для неизвестного Host.
6. `limit_req` для `/api/` с кодом 429.
7. Своя страница 404 и Basic Auth для `/admin`.
8. `proxy_next_upstream`, переключающий запросы на живой API при отказе второго.

После `docker compose up -d --build` запустите `bash lab1/check.sh`. Скрипт сам останавливает `backend-a`, проверяет ответ 200 от API и возвращает контейнер в работу. Для отчёта приложите конфиг, вывод скрипта и скриншоты работающей страницы и контейнеров.
